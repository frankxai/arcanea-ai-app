# Browser tools: public Library collections

State: implementation candidate; not merged or live-verified.

Scope: public collection search and retrieval on /library. Owner: Arcanea engineering. User job: find a collection by topic and inspect its public metadata and source URL.

Base: a42ddc8d3f6a3426feecbf646bc762d863bb77fe.

The Library page passes the same collection list it renders to a null-rendering client adapter. The adapter explicitly selects slug, name, description, read-when text, format and text count. It never reads account state, reading progress, private projects, provider keys or the authenticated world-context endpoint. No lore, source content, canon, licensing or publication policy changes. Results are untrusted data and do not grant reuse rights.

Search accepts 1–200 characters and at most 20 results. Lookup uses an exact public id; misses remain misses. Snapshots prevent callers mutating the source list. Registration is feature-detected, revoked on teardown, and failure leaves the page usable.

Validation: 14 adapter/catalog tests and an isolated strict typecheck of the new component pass. Existing CI now runs test:webmcp. Full monorepo lint/typecheck/build, rendered-browser checks and native WebMCP engine validation are pending; no production acceptance claimed.

Guidance: WebMCP imperative site-author contract; Modern Web Guidance progressive enhancement. No visual layout, motion, dependency, model request or network service is added. Existing public data is reused.

Rollback: revert the Library import/mount and additive modules. Independent exact-head review and full release gates are required before merge or promotion.
