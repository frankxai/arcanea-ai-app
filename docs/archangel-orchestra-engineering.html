3 · Web3 + NFT Integration Layer

Soulbound Achievement Tokens (SBTs)

Non-transferable, evolving, on-chain proof of achievement. When Frank completes a gate, a Soulbound Token is minted to his wallet. When an agent reaches a new rank, a corresponding SBT is minted to the agent's on-chain identity. These can't be sold — they're proof of work, not speculation.

Standards to use: EIP-5484 (Consensual Soulbound Tokens — requires holder consent) on Base or Polygon for low gas costs. Dynamic metadata via IPFS with updateable JSON — the NFT visually evolves as you progress through gates.
