# C — Atlas and encounter desk (selected)

Composition: the existing Arcanea cinematic hero leads into six connected works. A boss always links to its inhabited place. Dossiers stage a full artwork, a concise human conflict, then the encounter or spatial guide and a usable scene kit. The opening excerpt and trilogy outline supply a reading path without blocking direct exploration.
Typography: reuse the current gallery's display serif for names and its body/interface faces for reading and controls. No additional type family, font file or decorative label system.
Imagery: use the completed six individual images; preserve their native aspect ratios in dossiers. Art leads the first view; practical controls follow a readable explanation.
Interaction: native buttons select one encounter phase and one ending. The ending's consequence appears in the copyable session kit. Clipboard rejection exposes selectable text. Related links move between each boss and its place. These are authoring controls, not a playable combat simulation.
Motion: cut decorative animation so the artwork and changing text remain the focus. Selected-state feedback is immediate and complete in reduced motion.
Evidence: combines the observed Sovereign Depths presentation with the creative packet's nine authored phases, nine outcomes, six scene kits and six actual works.
Decision: selected by release approver `/root` before implementation. It satisfies the explicit request to make the art useful for stories and community while preserving Arcanea's established visual identity.
