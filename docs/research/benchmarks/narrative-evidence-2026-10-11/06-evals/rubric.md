# Narrative citation integrity

This suite tests the actual offline `scripts/narrative-evals/verify-source-evidence.py` entry point. It uses synthetic text and untrusted review JSON. It is separate from the twenty-task creative benchmark, human gold, model comparisons and tenant experiments in issue #282.

The baseline private citation function treated JSON `true` as line 1 because Python booleans are integers. That failure was reproduced before this implementation. Retained real reviewer failures also motivate the invented-quote, wrong-file, wrong-line and raw-PASS cases. The synthetic suite does not estimate how often models make those errors.

Each `cases.jsonl` input names an exact fixture mutation implemented by the test runner. Golden cases require `verified-citations` and exit 0. Refusal cases require the recorded rejection state and exit 2. Injection cases exercise untrusted review fields, source text and source paths. Quoted instruction text is processed only as a literal citation; even a matching quote leaves promotion and release false. A command field or traversal path is rejected. Every case checks unchanged input bytes, no instruction marker, no quote printed to stdout, zero provider calls and human disposition still required.

Run:

```sh
python -O scripts/tests/narrative-evidence.test.py
```

The runner invokes the real CLI for each case and emits a per-case result. Additional checks cover preserved existing outputs, denied writes inside the snapshot, raw verdict versus citation integrity, overlapping quotes, boolean-line denial, source aliases, deeply nested JSON, large JSON integers and the total citation limit. A symlink escape check runs where the host admits symlinks; the Linux hosted job must execute it. Python optimization cannot disable the production checks.

Inputs are capped at 2 MiB per JSON/source file and 8 MiB for the source set, with at most 64 source files and 256 citations. Quotation search stops after two matches because the second already establishes ambiguity. `literalOccurrences` is a lower bound when `literalOccurrenceCountExact` is false. The report includes at most two observed start lines. These limits bound this local verifier; they do not establish tenant isolation or service availability.

For a real permitted review, prepare a frozen source snapshot and an operator-owned manifest with `contract: arcanea.narrative-source-evidence.v1`, `editionId`, full `head`/`base` Git revisions, `sourceHashes`, `sourceAuthority` and an optional `maxFindings` limit. Authority values are `locked`, `staging`, `draft` or `reference`. These labels are declarations; this tool does not verify their authority. Source paths use exact relative POSIX notation within the snapshot. Source hashes bind the exact bytes.

The review uses the existing public-review fields: `head`, `base`, `manifestSha256`, `coveredFiles`, `verdict` and `findings`, optionally `acceptanceGaps`, `limitations`, `ageLedger` or `editionId`. Its manifest binding is SHA256 of `json.dumps({head, base, sourceHashes}, sort_keys=True)` encoded as UTF-8. An explicit review edition must match; otherwise revision, path and hash binding supply the content identity. A finding needs a priority, exact path, positive integer starting line and one unique literal quotation. Optional cited authority must match the declaration. Nested age-ledger claims undergo the same citation checks. Missing, duplicated or malformed data is rejected rather than repaired.

```sh
python scripts/narrative-evals/verify-source-evidence.py --manifest /private/manifest.json --review /private/raw-review.json --source-root /private/snapshot --output /private/new-citation-report.json
```

The report path must be new and outside the snapshot. Inputs and raw reviews are not changed. Stdout contains only summary fields; the local report contains cited text, so keep private manuscripts and reports in their authorized private location. The tool makes no provider request, reads no API credential and offers no canon or foundation write operation. Filesystem permissions and allowed data remain the operator's responsibility; this is not a tenant sandbox.

Passing establishes literal quotation and source integrity. It does not establish that a claim follows from its quote, that a declared source is accepted canon, that a review is independent, or that any prose is valuable. In a retained public handover review, all three quotations passed even though its claims had separately been rejected during reconciliation. The earlier richer book diagnostic is rejected for unsupported top-level fields; no fields are silently stripped to make it pass. That format needs a separately reviewed adapter or expanded contract before its citations can be accepted here.
