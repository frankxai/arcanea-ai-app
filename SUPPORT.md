# Support

## Product

Use [arcanea.ai](https://arcanea.ai) for the public product.

## Repository

Open a GitHub issue for:

- reproducible bugs
- documentation gaps
- package installation problems
- MCP integration issues
- clear feature requests tied to existing product direction

Do not open public issues for secrets, vulnerabilities, private data, or
commercial licensing questions. Use the private contact path described in
[SECURITY.md](./SECURITY.md).
