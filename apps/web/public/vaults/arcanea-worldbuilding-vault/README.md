## How to Use This Vault

### 1. For Writers, Authors & Narrative Designers
- Begin with **`LORE_MASTERY_COMPENDIUM.md`** to understand the metaphysical foundations and dramatic engine.
- Use **`02_character_forge/`** to build fully fleshed protagonists and antagonists using the **Character Diamond** (Desire, Wound, Mask, Truth).
- Consult **`01_faction_bibles/`** for faction alliances, political intrigue, and high-stakes world friction.

### 2. For Concept Artists, Directors & Visual Creators
- Study **`03_visual_doctrine/01_arcanea_visual_bible.md`** to master the **Cosmic Luxury Myth-Tech** aesthetic (avoiding generic fantasy mud or flat sci-fi spandex).
- Copy prompt recipes from **`03_visual_doctrine/04_visual_prompt_lexicon_50_prompts.md`** directly into Midjourney v6 or Flux Pro for magazine-grade visual consistency.
- Reference **`03_visual_doctrine/02_faction_design_standards.md`** for precise hex codes, lighting behaviors, and silhouette rules.

### 3. For Game Developers, Worldbuilders & Studio Leads
- Utilize **`04_magic_systems/`** to implement progressive level/rank progression (Apprentice → Mage → Master → Archmage → Luminor).
- Adopt the **Extended Solfeggio Frequency System** (174 Hz Foundation to 1111 Hz Source) for dynamic audio design and procedural magic effects.
- Deploy the **`06_interactive_reader/index.html`** in your studio for instant world canon lookup.

### 4. For Obsidian Second Brain Users
- Open Obsidian, select **"Open folder as vault"**, and choose the `05_obsidian_vault_bundle/` directory.
- Explore the interactive graph view, pre-configured canvas boards, and bidirectional wiki-links (`[[Lyssandria]]`, `[[Starlight Corps]]`, `[[Foundation Gate]]`).
