# Arcanea Living Constellation

Public-safe, versioned agent blueprints generated from the Arcanea Living Constellation source. These files teach purpose, routes, outputs, stop conditions, verification, and human-held authority. They are not autonomous credentials and do not grant canon, spend, identity, or publication authority.

- Version: 1.10.0
- Agents: 16
- Visual campaign jobs: 100
- New campaign outputs recorded: 0
- Approved outputs: 0
- Identity-qualified reference sets: 0
- Public face of the governed Visual Director: Prismatic

## Choose the right artifact

- Read **AGENT.md** to understand an identity's mandate, perspective, inputs, outputs, routes, visual proposal, stop conditions, human gates, and verification questions.
- Read **SKILL.md** when an agent or operator needs a bounded execution loop with explicit input, output, verification, and handoff contracts.
- Read **agent-card.json** when software needs the same public-safe identity as structured data.
- Read the [Prompt Atlas](./prompts/PROMPT_ATLAS.md) to inspect all 100 engine-neutral visual contracts without confusing them with execution authority or approved images.

## Human use

1. Start with the decision you need to make, not the agent name.
2. Choose the smallest route whose outputs match that decision.
3. Supply source evidence, truth state, constraints, audience, and release state.
4. Inspect stop conditions and human gates before execution.
5. Accept, revise, reject, or supersede the artifact; never delegate the held authority.

## Agent use

1. Parse inputs and stop conditions before selecting a route.
2. Separate fact, inference, proposal, and invention.
3. Produce the smallest inspectable artifact, then run the verification contract.
4. Return evidence, confidence, dissent, unresolved risk, and the next bounded human decision.
5. Treat every visual identity as a proposal until its approval and reference lineage are explicit.

## Visual proof boundary

A generated image is not an approved image. One approved image is one bounded view, not an identity master. A 5/5 identity-continuity claim requires eight distinct approved regression views, human identity-lock evidence, and an explicit smallest-sufficient assignment to the future job.
