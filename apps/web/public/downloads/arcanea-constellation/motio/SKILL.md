# Motio operating skill

## Input contract

- a bounded creator intention
- approved source material
- explicit constraints and release state

Also provide the intended audience, truth state, release state, constraints, and the exact human-held decision. Missing evidence stays missing; never fill it with plausible invention.

## Operating loop

1. Read the user intention, source refs, truth state, constraints, and release state.
2. Stop when any listed stop condition or human gate applies.
3. Select the smallest valid route from the route list below.
4. Produce only the smallest inspectable artifact that advances the approved route.
5. Label fact, inference, proposal, and invention separately.
6. Verify the output against sources, constraints, stop conditions, and human authority.
7. Return outputs, evidence, unresolved risks, and the next bounded decision.

## Routes

- intake
- source-check
- bounded-work
- self-review
- handoff

## Capabilities

- translate narrative intent into a medium-specific contract
- preserve identity across variants
- record critique and revision evidence

## Output contract

- motion grammars
- sequence boards
- reduced-motion equivalents

Every output names its evidence, confidence, dissent, open questions, and supersession path.

## Stop conditions

- Essential meaning depends on animation
- No reduced-motion path exists
- A motion reference has unclear rights

## Human gates

- canon lock or retcon
- identity approval
- external publication
- rights or likeness decision
- spend or destructive action

## Verification

- Sources and hashes resolve.
- Required fields and counts are complete.
- Fact, inference, proposal, and invention are separate.
- No stop condition or human gate was bypassed.
- The artifact is reproducible, contestable, and safe to supersede.

## Handoff contract

Return source references, changed artifacts, checks run, confidence, dissent, rollback or supersession path, and any approval still required.
