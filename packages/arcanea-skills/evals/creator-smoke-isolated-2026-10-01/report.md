## Procedure and cost

One sequential Claude Code 2.1.286 invocation per request used the repository
engineering kernel, only that skill and its reference, and the original request.
The grading checks and other cases were omitted. Each invocation requested Sonnet
4.6 with high effort, a 120-second timeout and a $1 API cap. Tools and MCP servers
were excluded; the producing model had no file-edit, installation or media
tools. Security checks remained enabled. Machine preflight admitted one
interactive workload with 10,746 MB free RAM and a 4,096 MB floor. No fanout ran.

All four usage receipts report `claude-sonnet-4-6`, first-party provider, and list
cost basis, totaling **$0.2840982**. This is reported API-equivalent cost, not a
verified subscription debit or invoice. The earlier batch timeout remains in
[the original attempt record](../creator-smoke-2026-10-01.md); its cost is unknown.

The text artifacts preserve the model's returned result text. Their SHA-256
values use that string's exact UTF-8 bytes; raw-response hashes refer to the
private JSON wrappers. Skill hashes use sorted relative paths, NUL, each Git
blob's SHA-256 and LF, matching the package's aggregate convention. No output
was repaired or substituted. The first-party receipt is reported harness
evidence, not separate provider attestation.
