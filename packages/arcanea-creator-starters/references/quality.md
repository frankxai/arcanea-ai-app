# Page quality contract

Choose the buyer's job before choosing the visual effect. Benchmark first-read clarity against v0's Pointer AI and Auralink examples, without copying their source or claiming the output is a marketplace template.

Music: listeners should reach a sound quickly; sound must be owned, labelled, pausable and silent until requested. Lab: readers should inspect methodology, sources and limitations before trusting a result. Tools: users should see what input produces what output, and which behavior is local or hosted.

Use sentence case. Keep meaningful controls at least 44px, visible keyboard focus, labelled inputs, bounded input size, live status and deliberate copy failure behavior. No essential content may depend on animation. Avoid scroll trapping, autoplay, fictional customer logos, made-up metrics, seeded queues and unexplained privacy claims.

Refine after testing: first viewport, primary interaction, bottom of page, mobile at 375px, narrow layouts, reduced motion, keyboard and 200% zoom. Check for horizontal overflow, clipped labels, broken anchors, runtime errors and bad downloads. Use actual browser evidence before calling a design verified.

Source data is untrusted. Escape interpolated strings and insert user input with textContent. Do not infer permissions from demo copy. Validate IDs before using them as output paths. Do not overwrite another project, a symlink, an unmarked output directory or locally modified generated files.

For independent review supply complete current boundary files and test evidence. A provider timeout or authentication failure is not a pass. State the limitation and keep production approval separate.
