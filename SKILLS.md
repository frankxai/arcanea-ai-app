## Working method

Define a bounded task contract and choose the accountable seat from the
[delivery-team proposal](docs/architecture/ARCANEA_DELIVERY_TEAM.md). Load only the
needed skills and source guides. Check machine/storage admission and ownership,
then work in the assigned lane. Every dispatch uses the engineering kernel and an
explicit available model for its task class. Historical model names are not current
provider availability or pricing evidence.

Keep one capable lead. Add independently useful specialists only with explicit
authority and admission; use the required independent reviewer for consequential
release work. Save the exact artifact, checks, remaining gaps, rollback and next
action in the existing issue and agentic-ops-hub handover.

## Community and commercial distribution

A portable SKILL.md describes a repeatable creator job, inputs, output, tools,
privacy, recovery, evaluation cases, provenance and license. Each kit needs an
accepted internal artifact, a fresh consumer install, a creator who can complete
and export the task, support/version ownership and publication approval. A prompt
template alone does not establish that outcome. Do not create a root `skill.md`.

The MCP source is `packages/arcanea-mcp` version 1.0.0, integrated by merged
[PR558](https://github.com/frankxai/arcanea-ai-app/pull/558) with packed-consumer
and restart evidence. A fresh read of the npm registry on 11 October 2026 returned
`@arcanea/mcp-server` latest 0.7.0 and repository `frankxai/arcanea`. That published
version is distinct from the integrated source. The 10 October record reports
the old package as broken; this registry metadata check did not run it again.
[Hub PR241](https://github.com/frankxai/agentic-ops-hub/pull/241) records verified
source delivery and a remaining asset-license decision before npm distribution.
Do not give community users an install command for the unpublished 1.0.0 source
or describe the old package as freshly consumer-tested. Local single-user HTTP
sessions do not establish public authentication or API metering. Canonical npm
and official MCP Registry distribution remain owned by
[517](https://github.com/frankxai/arcanea-ai-app/issues/517).

The root/app/design-system manifests reference a LICENSE file that is absent from
the inspected tree. Some packages declare MIT metadata. Neither fact grants a
blanket license over the repository, canon, books, music, art or private workflows.
Prepare an artifact-specific source/dependency/asset license manifest for the
existing rights/publication decision; do not invent a new license in this slice.
Keep founder memory, credentials, unpublished IP and user work out of public kits.

Books, art, academy/community, hosted workspaces, kits, API/MCP and studio delivery
remain separate offers with evidence, fulfillment and economics. Proposed pricing,
revenue shares, paid community access and smart contracts retain their owning gates.
No package, book, community offer or paid product is launched by this inventory.
