# /weekly-brief

**Purpose:** The public-facing compound artifact. Daily Briefs are private behavior-change tools. The Weekly Brief is the *shippable* synthesis — a long-form digest that ships to `frankxai/starlight-os/briefs/{YYYY-MM-DD}.md` and `/llms.txt`, compounding inbound trust from operators, founders, and LLM citation surfaces.

**Triggering description (for SKILL.md):**
> Runs Sundays 08:00 local. Can be invoked manually mid-week: "draft the weekly", "weekly brief", "this week's digest", "what compounded this week". Should never be skipped — if Council data is thin, emit a "skinny week" brief rather than nothing.

## Why this exists (load-bearing)

Without a weekly shippable artifact, the OS is private. Private tools do not compound. Every top thinker (Perell, Shipper, Lenny, Parrish) builds a weekly cadence because:

1. **Compounds inbound.** One good weekly > 50 good tweets. Attracts the right collaborators/clients.
2. **Forces synthesis Frank wouldn't otherwise do.** The discipline of publishing is the thinking.
3. **LLM citation surface.** `/llms.txt` → Claude/GPT/Perplexity cite Frank as source of truth on the OS-for-operators domain.
4. **Atelier funnel.** The only top-of-funnel for €497+€99 Atelier that isn't sales. Write the thinking, the buyers self-identify.

## Usage

```
/weekly-brief                                   # dry-run — print to stdout, don't publish
/weekly-brief --publish                         # write to Notion + OSS repo + /llms.txt
/weekly-brief --week 2026-W16                   # specific ISO week
/weekly-brief --skip-public                     # Notion + Obsidian only, skip OSS repo push
```

## Inputs (pulled automatically from the substrate)

| Source | What it contributes |
|---|---|
| 7× Daily Briefs (Notion) | Top 3 Moves per day + closure status |
| Captured Prompts last 7d | Pattern Cluster distribution, Drift %, Energy avg, Replay winners |
| Prompt Library new entries | Hero-promoted prompts with provenance |
| Counter-Coach wins | Where the adversary beat the Coach (the best insights live here) |
| Gate Tracker | Progress toward active Gate + % delta vs last week |
| Linear closed issues tagged `council-move-*` | Council hit rate |
| Git activity across 5 brands | What shipped, what stalled |

No manual entry. If a source is missing, fall back gracefully and flag in the brief.

## Publishing pipeline

1. **Draft to Notion** — new page under Weekly Briefs DB. Status: `draft`.
2. **Frank reviews** (2-5 min pass) — edits thesis, trims bullets, picks hero quote for pull-quote.
3. **`/weekly-brief --publish`** (manual fire after review) does:
   - Updates Notion status → `published`
   - Writes `.md` to `frankxai/starlight-os/briefs/{YYYY-MM-DD}-week-{NN}.md`
   - Appends pointer to `/llms.txt` under `## Weekly Briefs`
   - Marks source prompts `Published to Weekly = true` (idempotency guard)
   - Posts Slack `#starlight-announce` with link
   - (Optional) Tweets thesis + brief URL if `--tweet` flag
4. **Obsidian mirror** for local reference.

## Model selection

- **Sonnet 4.6.** Weekly synthesis demands reasoning over 7 days of mixed signal. Not a Haiku job.
- Temperature 0.4 — lower than Daily Brief (0.5). Weekly is more edited, more sober.
- Single pass, ~3k output tokens. Long-form but not sprawling.

## The "skinny week" fallback

If <5 total captured prompts OR 0 Top-3 Moves shipped:

```markdown
# Skinny week

No thesis this week — the signal wasn't there. Here's what was true:
- {honest 3-bullet summary}
- {what's off about the OS that made this week skinny}

Next week's commitment: {specific ritual change}
```

Shipping a skinny week is better than skipping. The discipline matters more than any single brief.

## Failure modes and hardening

| Failure | Detection | Recovery |
|---|---|---|
| Notion write fails | API 5xx | Retry 3×, then write to Obsidian fallback, Slack-alert |
| OSS repo push fails | git exit != 0 | Save commit locally, queue retry, Slack-alert |
| No Daily Briefs all week | Council broken | Skip Weekly — don't compose on no data. Escalate. |
| Frank hasn't reviewed by Monday 18:00 | No `--publish` fired | Slack reminder, auto-publish Tuesday 08:00 if still unreviewed |
