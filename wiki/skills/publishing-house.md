# Publishing House (Arcanea)

Full coordinated publishing swarm on Hermes Agents.

**Install the profile:**
```bash
hermes profile install github.com/frankxai/arcanea-publishing-house --name publishing-house --alias --force -y
publishing-house chat
```

**Core Lanes**
- Book production pipeline (with lore/world consistency)
- Marketing swarm (ads + organic)
- Influencer outreach
- Swarm Sun Agents with their own social profiles (X, IG, etc.)

**Key Skills**
- book-production-pipeline
- swarm-social-poster + social-profile-manager
- influencer-outreach
- ad-campaign-orchestrator
- publishing-orchestrator

**Architecture & Replicability**
See https://github.com/frankxai/arcanea-publishing-house

Ties into existing Arcanea book/, ship-public, ship-it patterns and SIS memory.

Evolves the creative output loop from idea → published + promoted.
