# 04-Sparks/

Zero-ceremony captures. `/capture` writes here. Triage to atom, project, or delete within 7 days.

## Structure

```
04-Sparks/
└── 2026-04-21-open-core-cannibalization.md
```

## Frontmatter (minimal)

```
---
captured: 2026-04-21T11:42:00Z
source: chat | reading | walk | shower | meeting
---
```

## Rules

- 1 file per spark — don't batch
- No editing; if a spark needs edits, it's already an atom
- `/inbox-triage` (daily 09:00) processes this folder
- Sparks older than 7 days without triage → auto-move to `09-Archive/sparks/{year}/`
- Orphans are expected here — this is the unfiltered input layer

## The triage verdict

Three outcomes:
1. **Promote** → becomes atom in `05-Atoms/`, credits source spark
2. **Merge** → appended to existing atom or MOC
3. **Delete** → not every spark deserves to live; this is fine

See [[../skills/inbox-triage]] (if specced) and [[../meta/second-brain-v2-architecture]].
