## Second Brain Integration Map

Which skills feed which layer:

```
CAPTURE LAYER
  /capture ──────────────────────────────► ARC-INBOX
  /confidential-capture ──────────────────► T1 stores (never ARC-INBOX)

TRIAGE LAYER  
  /inbox-triage ──────────────────────────► Projects from ARC-INBOX
  /harvest ───────────────────────────────► ARC-INBOX (7 buffers)

EXECUTION LAYER
  /daily-ops ─────────────────────────────► Session context
  /session-sync ──────────────────────────► Linear + Notion + planning files
  /arcanea-orchestrator ──────────────────► Cross-repo coordination
  /gate-eval ─────────────────────────────► Gate 0-5 status
  /lock-decision ─────────────────────────► wiki/decisions/ ADRs

OUTPUT LAYER
  /ship-it ───────────────────────────────► wiki/milestones/ + social drafts
  /repo-triage ───────────────────────────► wiki/reports/ + Linear archive
  /claws ─────────────────────────────────► Social posting (5 agents)
  /publish-distribute ────────────────────► Content pipeline
  /arcanea-orchestra ─────────────────────► Gate execution system
```
