# Andrej Karpathy

**AI researcher + operator. Previously Tesla, OpenAI. LLM-first knowledge architect.**

## The idea I steal

**LLM-indexable atomic notes.** A personal wiki where each page is self-contained, aggressively backlinked, and readable by a language model for retrieval. The file isn't the unit — the graph is.

## Where it shows up in the OS

- `05-Atoms/` folder exists because of this

- Every atom's frontmatter follows the Karpathy shape

## Canonical source

His informal tweets about personal LLM-wiki + his eval-driven thinking approach. No single book. (Could cite "Karpathy's scaling laws" but that's unrelated.)

## Counter-read

Cal Newport — *A World Without Email* — argues against tool maximalism; atomic notes can become attention-shredding if each idea-shard demands a context switch. Worth holding the tension.
