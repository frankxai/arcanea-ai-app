## Close-out ritual

When a project ships:
1. Write post-mortem in `learnings/`
2. Extract durable atoms from the project into `05-Atoms/`
3. Move entire project folder to `09-Archive/{year}/`
4. Update [[../00-MOCs/MOC-Projects]] and [[../00-MOCs/MOC-Shipped]]

## Rule

Don't leave projects here "just in case." `/vault-atlas` flags projects untouched >14 days as stale.
