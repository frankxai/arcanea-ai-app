# 08-Resources/

Reference material. Book notes, framework documentation, people dossiers, research artifacts.

## Subfolders

- `books/` — one atom per book (see [[../00-MOCs/MOC-Books]])
- `people/` — dossiers on people Frank works with or references
- `frameworks/` — external methodologies (when reference is needed beyond the atom)
- `research/` — primary source captures

## Rule

Resources are **reference**, not workspace. Don't do project work in 08-Resources/. If you're making a decision based on a Resource, link to it from the Project or Atom — don't embed the decision here.

## Migration note

Existing `wiki/people/`, `wiki/music/`, legacy `wiki/{brand}/` content migrates here on demand via `/harvest`. No bulk migration — harvest pulls what's actually referenced.
