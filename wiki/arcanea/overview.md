# Arcanea

Intelligence systems that visualize magic with AI — and help creators build thriving ecosystems around their brand.

## North Star

BYOK-first creative intelligence workspace. Core product: projects, continuity, docs, memory, creations, provenance, workflow orchestration, creator compounding.

## Architecture

Next.js 16 (App Router) + React 19 + TypeScript (strict) + Tailwind + Supabase + Vercel AI SDK. Deployed on Vercel (arcanea-ai-appx). See [[arcanea/architecture]].

## Sub-Products

- **VibeOS** — consciousness operating system (music, alignment protocols)
- **GenCreator** — community OS for AI-native creators
- **ACOS** — Agentic Creator Operating System (autonomous pipelines)
- **Arcanea Platform** — worlds, characters, stories, games, agents

## Current State (April 2026)

- 42/42 packages BUILD PASS
- 16 systems live/built
- 1M+ words content (17 collections, 23 book covers)
- 42 MCP tools (SDK 1.29)
- 10 Luminor prompt modules
