# 00-MOCs/

Navigation layer. Entry points for the vault. Hard cap: 12 files.

See [[MOC-Second-Brain]] for the master index.

## Rules

- One MOC per big domain, not per category.
- MOCs are markdown pages of links + 1-line annotations — never essays.
- If an MOC exceeds 40 bullet points, split or promote content.
- If an MOC goes 30 days without update, flag via `/vault-atlas` for kill-or-refresh.
