## Anti-frameworks (things we explicitly don't do)

- Zettelkasten numeric IDs — atoms use titles, not `202604211547`
- GTD context tags (@phone, @computer) — all work happens on one machine
- Building in Public maximalism — shipping public is gated by veto + audit, not default
- 30-minute time blocks — pomodoro lives in Vibeclubs, not life ops

## How to add a framework

Only add a framework-atom if Frank uses it more than once and it's load-bearing on at least one skill, project, or brand. Frameworks that don't compound across contexts live in 08-Resources/frameworks/ as reference only.
