# Books — Map of Content

Book-atoms live in `08-Resources/books/`. Each: the one idea stolen, where it shows up, read date.

## Rule: one atom per book

Not one atom per chapter. Not one atom per highlight. **One atom per book.**

The book-atom follows:
```
---
title: {Book title} ({Author})
tags: [book, {domain-tags}]
read: 2024-XX
---

# {Title}

**The one idea I took.** (1 sentence)

**Where it shows up in the OS.** 2–4 links.

**Counter-read.** (1 book that disagrees — keeps the idea falsifiable)
```

## Currently seeded (placeholder — migrate on demand)

Currently 0 book atoms. Populate as Frank references books in Captured Prompts — `/harvest` picks up the reference and stubs the atom for later completion.

## Reading pipeline

Books aren't a TODO list here. Active reading lives in Notion or Obsidian Kindle sync. **This MOC only tracks books that have shipped an idea into the OS.**

A book without an atom ≠ unread. It means the book hasn't compounded anything yet.

## Counter-read rule

Every book-atom gets paired with a book-atom that disagrees with it. If no counter exists in the vault, flag it in [[MOC-Patterns]] as `counter-move` cluster for reading list.

Naval: *"A book without a counter is dogma."*
