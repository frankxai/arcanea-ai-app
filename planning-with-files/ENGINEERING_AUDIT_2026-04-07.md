### Architecture Audit

**97+ API routes inventoried. Key patterns:**
- 3 auth strategies in same codebase (middleware session, Bearer token, admin key) — inconsistent
- Internal API-to-API calls (`/api/ai/generate-image` fetches `/api/credits/spend`) — anti-pattern
- In-memory rate limiting (Map-based) — doesn't persist across serverless cold starts
- No CSRF protection on POST endpoints
- No server actions (`'use server'`) — all client-side fetch patterns
- Duplicate flow library: `reactflow` v11 AND `@xyflow/react` v12

**Dependencies:**
- `reactflow` → remove, use `@xyflow/react` only
- `js-yaml` 3.14.1 → upgrade to 4.x (2 years old)
- `typescript: { ignoreBuildErrors: true }` in next.config — hides real issues
