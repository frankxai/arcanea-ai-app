The schema defines optional game, memory, meaning, community and mapper sections over its base1.0 contract. The old partial validator ignored them, omitted most nested/type/bound checks and accepted unknown closed fields. The builder discarded the sections and an explicit version. A fixed-schema zero-dependency evaluator now checks the accepted schema's used keywords, with Unicode code-point lengths, distinct null/absence and JSON-data checks for open payloads. Unknown schema keywords refuse on load. Unknown instance keys refuse at closed nodes; additional content roots and open state/contributor/procedural metadata remain supported. Cycles, accessors, sparse arrays, nonfinite numbers and non-JSON values refuse. Validation changes no input, applies no defaults/coercion and fetches no URI.

JSON Schema2020-12 `format` is an annotation here, including date-time. Existing SDK nonempty SPDX/provenance timestamp and nonempty royalty-split total checks remain explicit extra semantics. Type declarations cover the five sections, unknown validator input and the already-supported Grok assignment. `buildManifest` preserves explicit schemaVersion and known supplied extensions, omits undefined optional extensions, and keeps default1.0.0. `scaffoldWorld` validates the emitted manifest before optional world-engine import or destination writes, using a constant sanitized `ERR_ARCANEA_WORLD_MANIFEST` refusal. `createWorld` inherits that boundary. Existing invalid files remain inspectable/readable for creator repair; the general `writeManifest` primitive is not made a validator. Later filesystem failures are still not an atomic scaffold transaction.

The schema's legacy Higgsfield-named fields are retained as existing data shape only; no Higgsfield tool, skill, asset generation or provider call occurred. Shape validation does not establish privacy classification, provider permission, copyright, commercial licensing, canon promotion or publication authority. Existing license/royalty defaults require separate disposition; passing shape checks cannot approve them. The declared-public-v1 proof-claim block and memory-to-canon refusal remain unchanged.
