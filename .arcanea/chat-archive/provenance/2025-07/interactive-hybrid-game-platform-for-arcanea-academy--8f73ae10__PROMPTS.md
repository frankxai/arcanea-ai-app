## Turn 0

You are a senior game developer, AI agent, and educational experience designer. Build the first version of an interactive hybrid game platform for Arcanea Academy, connecting physical experiences (on a boat, in a home studio, or at local landmarks) with a digital/metaverse journey.

**Goal:**
- Create a prototype web application (React/Next.js or Python/Streamlit, your choice) that allows users (kids, parents, or entrepreneurs) to join real-life events and quests, collect digital achievements (badges), and unlock further digital/virtual content (videos, code/music challenges, AR clues).
- The app should allow:
    - Users to register/login
    - Event/quest selection (location, date, type)
    - Progress tracking (completed quests, badges earned)
    - Integration with a digital map (basic, can use Google Maps or Mapbox) to show physical quest locations and digital twin versions (for remote/metaverse play)
    - Admin area for adding/editing events, content, and digital rewards

**Extra Points:**
- Suggest or scaffold simple mobile AR integration (e.g., scavenger hunt QR codes, AR clues at physical locations).
- Make the frontend easily brandable (Arcanea: Starlight Intelligence Studio theme, modern UI, space/magic/tech vibe).
- Modular, well-documented code for easy extension (adding more locations, quests, or digital content).
- Propose a simple backend/data structure (can use Firebase, Supabase, or Replit DB for MVP).

**Deliver:**
- Project folder structure and setup instructions
- Core components/pages code (user auth, map/quest selection, progress, admin)
- README file explaining how to run and extend the project
- [Optional] Sample AR integration or placeholder for future AR/metaverse upgrades

Ask for clarification if anything is unclear, and provide recommendations for scaling and connecting to future metaverse or VR spaces.
