This is both your personal tool AND the open-source product you ship to creators. They install `arcx`, authenticate with Arcanea account, and their Vault syncs.

## Layer 2 — Arcanea Vault

**Architecture:** Local-first (SQLite + LanceDB vector store) → Google Drive as sync layer → Supabase for multi-device auth and shared collections.

**Schema — everything is a `Relic`:**
```
Relic {
  id, type (prompt|image|video|audio|code|lore|artifact)
  source (claude|chatgpt|grok|gemini|local|arcx)
  content, embedding, metadata
  tags[], guardian_affinity[], godbeast_affinity[]
  created_at, session_id, project_id
  vault_path (local), drive_path (synced), ipfs_cid (future)
  visibility (private|community|public|tokenized)
}
```

**Ingestion flows:**
- **ChatGPT**: ZIP export parser → extract conversations, images, code blocks → Relic creation
- **Claude**: Export JSON + artifacts folder → parse
- **Grok**: API or export → parse
- **Live capture**: `arcx` writes every session automatically
- **Drag-drop**: local files → auto-classified by Gemini Vision + Twelve Labs

**Knowledge graph layer** (on top of vector store): relationships between Relics — "this image came from this prompt, which evolved from this conversation, used in this video, referenced in this lore doc." This is the moat. No one else has this.

**Prompt Books** = curated collections of Relics with metadata. `arcanea.ai/prompt-books/frankx` is a publishable view of your best prompts, filterable by Guardian, style, model, outcome.
