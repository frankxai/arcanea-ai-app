# The Key Architectural Decision

You need a **canonical registry** — a single source of truth that maps:

```
Entity → Archetype → Agent Spec → Content Domain → Embodiment Practice
```

Example row:
```
Draconia → Builder/Forge → construction-agent.skill → technical tutorials, GitHub → strength training, forging breath
```

Without this registry, you get narrative sprawl. With it, every new agent, every new piece of content, every new practice **automatically has a place** because it maps to an existing entity or justifies the birth of a new one.

# Acceleration Mechanics

"Infinite expansion" needs a rule system or it's just entropy. The universe in Arcanea should expand the way the actual universe does:

- **New agents = new stars** — each one creates a local gravity well
- **Swarms = constellations** — coordinated agents form recognizable patterns
- **Content = light** — what radiates outward from each gravity well
- **Community members = travelers** — they navigate by the constellations, drawn to gravity wells

The Starlight Orchestrator's job isn't command-and-control. It's **cosmological gardening** — deciding which gravity wells to amplify, which constellations to connect, which regions of the ultraworld to illuminate next.
