## What Changed and Why

The first page I made was exactly the problem you identified — it was **AI designing what AI thinks "premium" looks like**: dark background, purple gradients, rounded glass cards, DM Sans, everything centered, every section following the same overline → title → description → card grid template. That's the statistical median of every Tailwind tutorial from 2020-2024. It's polished slop.

The v2 takes a completely different approach:

**Light theme on purpose.** Dark with glowing gradients is what every AI defaults to. A warm bone-colored editorial layout with black ink typography immediately signals "a human designer made this choice."

**Bricolage Grotesque + Newsreader.** These are distinctive, characterful fonts that no AI defaults to. Bricolage has optical sizing and personality. Newsreader is a proper editorial serif. Together they create a Pentagram-level pairing.

**Asymmetric editorial grid.** The hero is a two-column layout with left-heavy type and a right-side aside. Brands are presented as table rows (like Bloomberg or FT), not cards. Icons use a replacement list format. Agents are a numbered horizontal flow diagram, not six identical cards.

**No section repeats the same template.** Hero = split editorial. Rules = full-bleed dark strip with numbered grid. Brands = table rows. Icons = sticky heading + list. Gradients = full-bleed dark with real specimens. Agents = numbered flow. Figma = binary split verdict. Stack = actual data table.

**The Anti-Slop Diagnostic** at the bottom is a checklist that gets run before anything ships. And the updated SKILL.md now leads with the Anti-Slop Protocol as the very first thing any Claude Code agent reads.

The key insight from the research: **specific context produces distinctive design. Generic prompts produce generic results.** The SKILL.md is now the "specific context" that prevents every future output from falling into the median.
