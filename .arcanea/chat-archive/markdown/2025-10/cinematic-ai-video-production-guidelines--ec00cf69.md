## CORE PRODUCTION STANDARDS

### Technical Specifications
- **Resolution**: 8K native output (7680×4320) or 4K minimum (3840×2160)
- **Frame Rate**: 60fps for smooth motion, 120fps for slow-motion sequences
- **Color Space**: Rec. 2020 wide gamut, 10-bit color depth minimum
- **HDR**: Dolby Vision or HDR10+ compatible
- **Motion**: High-frame interpolation enabled, optical flow smoothing
- **Bitrate**: Maximum quality settings, minimal compression artifacts

### Cinematography Standards
- **Camera Movement**: Specify exact trajectory (tracking, dolly, crane, orbit, handheld stabilization level)
- **Distance/Framing**: Precise measurements (e.g., "5–10 meters," "close-up 0.5m," "wide establishing 50m+")
- **Lens Characteristics**: Focal length equivalent (24mm wide, 50mm standard, 85mm portrait, 200mm+ telephoto)
- **Depth of Field**: Shallow (f/1.4–2.8) or deep focus (f/8–16)
- **Stabilization**: Gimbal-smooth, handheld shake intensity (subtle/moderate/intense), or locked-off

## REVISION PROTOCOL

**If output is unsatisfactory:**
1. Isolate the problematic element (camera/lighting/motion/subject/environment)
2. Add more specific technical descriptors for that element
3. Reference specific film/photo/art precedents
4. Simplify complex scenes into multiple prompts
5. Test individual transitions separately before full sequence

**Common fixes:**
- "Camera too unstable" → Add: "gimbal-stabilized, smooth tracking, minimal shake"
- "Lighting flat" → Add: "strong directional key light from [direction], 3:1 ratio, motivated by [source]"
- "Colors wrong" → Add: "Color grading: [film stock] emulation, [specific LUT], [saturation level]"
- "Motion blur excessive" → Add: "Natural motion blur, 180-degree shutter, sharp subject"
- "Subject inconsistent" → Create detailed character sheet prompt first, reference in each scene
