## The "Always Building" Visibility System

**The core principle:** You're not faking progress - you're *systematizing the surfacing* of work you're already doing.

---

### 1. Weekly Artifact Rhythm

Pick one day (Friday works well) to produce **one tangible output** that can be shared upward or outward:

- **Week 1:** Refreshed GenAI workshop deck with new customer examples
- **Week 2:** Industry-specific deck (pick one vertical - FSI, Healthcare, Retail)
- **Week 3:** Use case list update + Confluence cleanup with "what's new" summary
- **Week 4:** Architecture diagram (this is where your Claude Code automation investment pays off)

Ship a quick Slack/email to your manager: *"Updated X this week, adding Y based on recent customer conversations."* Short. Confident. Done.

---

### 2. Client Win Documentation

Create a simple running doc - "AI CoE Impact Tracker" - with columns:
- Client name
- Challenge
- What we delivered
- Outcome/quote

When you have 3-5 solid entries, that becomes LinkedIn content AND your raise justification artifact. Your manager sees it, leadership sees it, the internet sees it.

---

### 3. The LinkedIn Leverage Loop

You're already thinking about this - make it systematic:

- **1x per week:** Post something from your Oracle AI work (insight, architecture pattern, workshop reflection)
- **Tag Oracle, tag your CoE, tag relevant people**
- Screenshot engagement, add to your impact tracker

This isn't vanity - it's documented external validation of your expertise.

---

### 4. The Automation Investment

For the draw.io architecture automation via Claude Code - this is smart. Build it once, then every new architecture becomes a 10-minute task instead of an hour. That compounds fast.

Start with a template library: common Oracle OCI patterns, GenAI reference architectures, integration flows. Then Claude Code fills in the specifics.

---

### The Mindset Shift

You're not "seeming busy" - you're **building a portfolio of proof** that exists whether anyone's watching or not. The raise conversation becomes: *"Here are 20 artifacts I shipped, 8 client wins I documented, and the external recognition I generated for the CoE."*

That's not politics. That's leverage.
