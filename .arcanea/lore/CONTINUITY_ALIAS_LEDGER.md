# Arcanea Continuity Alias Ledger

This ledger records forward naming and terminology decisions for the Confluence canon packet. It is a migration guide, not a bulk rewrite order.

## Character Aliases

| Legacy / Draft Name | Forward Public Name | Status | Rule |
|---|---|---|---|
| Kael Thornfield | Arion | Migration proposal accepted for new Confluence packet | New public Confluence docs use Arion. Do not bulk replace old book files until a dedicated cast migration pass. |
| Kael Ashenvane | Arion | Legacy draft alias | Treat as older alternate continuity. |
| Five-Fold channeler | Confluence Avatar or Confluence Bearer | Term migration | "Five-Fold" may appear as an old academic term inside dialogue or archive texts. |
| Mira Tidecrest | Mera Tidecrest | Migration proposal accepted for new Confluence packet | New public docs use Mera. Existing Mira passages become source material for Mera. |
| Emilia | Emilia | New staging center | No existing canon conflict found in first pass. Surname remains TBD until naming audit. |
| Crew Akamoto | Headmaster Akamoto / Akamoto Roost / Crew Akamoto | Development expansion | Crew remains a Bonded recon unit; Headmaster Akamoto leads its academy/roost expression. |
| Malachar Lumenbright | Malachar | Locked | Do not rename. He is the antagonist anchor. |

## Place And Institution Aliases

| Legacy / Risk Term | Forward Term | Rule |
|---|---|---|
| Atlantis | Thal'Maris, Abyssal Athenaeum, the Sunken City | Do not use "Atlantis" in public Arcanea canon. |
| Atlantian / Atlantean Academy | Abyssal Athenaeum or Thal'Maris Academy | Use the specific institution or city name. |
| Four nations | Realms, Spheres, Houses, Orders, Origin Classes | Arcanea's political map is layered, not four elemental nation-states. |
| Avatar nations | Confluence Compact institutions | The Avatar is supported by a compact, not by nation ownership. |

## Migration Policy

1. New Confluence files use forward names immediately.
2. Old book bible files remain untouched until a controlled story migration pass.
3. Any bulk rename must include:
   - grep report before/after;
   - continuity review;
   - character voice check;
   - user approval if a locked/canonical doc is altered.
4. Public-facing files must remove or transform direct external franchise references before release.
5. Staging docs may preserve source provenance, but that provenance is not marketing copy.

## Known Risk Areas

- `MASTER_SERIES_BIBLE.md` currently calls Kael Thornfield canonical; this ledger supersedes only for new Confluence staging, not the historical file.
- `PRISM_LUXIN_SYSTEM.md` explicitly names an external series and should be treated as internal staging research until de-franchised.
- Headmaster naming is inconsistent across Academy docs. Akamoto should not replace Aelindra, Celestine, Theron, or Nerissa. He is the Bonded/dragon-rider headmaster, not the head of all Academies.
- Mera and Mira are too close to preserve as separate central characters without reader confusion. Merge unless a later audit finds a strong reason to split.

## Acceptance Criteria For Public Release

- Public pages use bending as a core Arcanean magic term with Arcanean qualifiers, mechanics, costs, and institutions.
- No public page pitches Arcanea as a direct version of another franchise.
- Arion and Mera are the first names seen in Confluence-facing surfaces.
- Kael/Mira remain discoverable only in archive, research, or migration context.
- Confluence Avatar, Confluence Bearer, Prism State, and Source threshold have consistent definitions.
