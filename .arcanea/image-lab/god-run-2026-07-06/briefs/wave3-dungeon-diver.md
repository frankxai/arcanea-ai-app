# Wave 3 briefs — Dungeon Diver arc, story sequence (god-run-2026-07-06)

Format: L99 universal prompt block. Global avoid block applies to every brief:
generic fantasy splash art, AI-maximalist ornament, random filigree, tangled glow trails,
fake tiny text, unreadable glyph noise, malformed hands, waxy skin, extra jewelry,
arbitrary straps, overexposed bloom, cyan-magenta neon overload, generic Atlantis,
Avatar franchise cues, mermaid tropes, superhero spandex, game loot armor,
one-hue teal/gold wallpaper, watermark.

Brand palette everywhere: Atlantean Teal #00bcd4 / Cosmic Blue #0d47a1 / Gold #ffd700 on #09090b.

Canon anchors for this wave: the Foundation Gate's corrupted dungeon is the **Hollow
Root** beneath the Ironwood Forest, inverted from the original Foundation Temple
(`.arcanea/lore/guardians/lyssandria.md`, `.arcanea/lore/godbeasts/kaelith.md`) —
"gravity manipulation and crushing depths," "stability becomes quicksand." The bonded
Godbeast of that Gate is **Kaelith** ("gravity-dense, near-indestructible... absorbs
kinetic force"), used here as the titan-scale Godbeast the corrupted dungeon has warped
and enraged. This wave uses the Hollow Root as the dungeon site — a real canon location,
not an invented one — to keep the Dungeon Diver arc anchored to existing lore rather
than a new unnamed dungeon. Mamoru briefs are flagged **STAGING lane** per
`STAGING_MAMORU.md` and must not be captioned as canon.
