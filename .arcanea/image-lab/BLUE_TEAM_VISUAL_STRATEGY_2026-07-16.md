## 2. Locked Core Design System — 10 non-negotiables

These are the **forever pillars**. Agents may not “soft fail” them for speed.

| # | Non-negotiable | Operational test (fail = block ship) |
|---|----------------|--------------------------------------|
| **1** | **Luxury cosmic myth-tech house look** | Read as Villeneuve × high fashion × living crystal — **not** mud-medieval, isekai glow, neon cyberpunk primary, MCU spandex, chibi, pure Midjourney chaos. |
| **2** | **Materials whitelist only** | Every surface maps to pack whitelist (crystal, starlight metal, living stone, nacre, Vael crystal, Otome Resonite, Laeylinn Jade, etc.). Plastic / mud default / random metal scrap = fail. |
| **3** | **Light law** | Warm gold × cool cosmic blue; cosmic dusk; restrained rays; domain accent **secondary**. Flat gray or neon-primary = fail. |
| **4** | **One subject per flagship** | One cast **or** one Godbeast. No multi-entity collage flagships. Scale helpers (tiny figure) only if silhouette of beast still dominates. |
| **5** | **Identity lock** | Cast: face master + **prop DNA** + silhouette. Godbeast: form bible (3 angles + material swatch) + silhouette. After first approve, **masterRef** mandatory. |
| **6** | **Godbeasts are creatures** | Never armored humanoids as “Godbeast origin.” Bonded humans are cast, not beast. |
| **7** | **FX budget = 1 + ambient** | Max one domain effect; ambient particles optional. **Zero** baked text, logos, sheet-music glyphs, cartoon hearts-as-architecture, emoji magic. |
| **8** | **Encyclopedia grammar** | Frame as museum plate / Codex source — not wallpaper dump, not MMO login splash, not raw lab contact sheet as public post. |
| **9** | **score30 ≥ 28** | Ship bar 28; iterate 22–27 once; restart ≤21. Dimensions: identity, silhouette, materials, light, composition, lore beat, anti-slop/glyph, motion readiness, franchise distinctness, channel fit. |
| **10** | **Human approve before public** | Only paths under `approved/` (+ deterministic overlays) may enter social queue / product marketing. No auto-post from lab runs. |

### Dual-rail forever (pillars’ spine)

| Rail | Authority | Allowed outputs | Hard ban |

| **RAIL-W World** | VISUAL_DOCTRINE + `house-myth-tech` | Codex, cast, Godbeasts, books, world social | Product chrome language; invent-a-verse silhouettes |

## 3. Prompt & production techniques to ADOPT (forever toolkit)

| Technique | Adopt how | Defends against |
|-----------|-----------|-----------------|
| **Design cards** | Mandatory schema before compile: id, entity_class, name, role, gate/domain, silhouette, materials, palette, light, environment, camera/crop, pose_beat, prop, identity_lock, forbidden, motion_seed, stylePackId, rail | R6 prompt soup |
| **Identity locks** | Cast face bible (front / ¾ / profile + costume plate); Godbeast form bible; prop lock string always named | R1, R7 drift |
| **Material whitelist** | Inject from `style-packs/house-myth-tech.json` every compile | Generic fantasy materials |
| **Seed / ref consistency** | Contact sheet 2–4 → pick → thereafter **img2img / face-ref / Soul** from master only | R5, R7 lottery |
| **I2V motion seeds** | Written **with** the still; grammar: slow push-in/orbit, material shimmer, hair/water/dust micro-motion; no morph/new limbs | R15 chaos video |
| **Codex overlays** | Name · Gate · one line via deterministic HTML/Satori — never gen text | R8 |
| **Contact sheets** | Compare candidates side-by-side; log rejects in evidence | Silent mediocrity |
| **Face bible** | Before volume or Soul ID train; human face approval first | Uncanny cast |
| **Negative-as-positive** | Prefer “clean encyclopedia crop, single domain light-thread” over “no hands no text no watermark…” spam | R14 |
| **Multi-pass edit** | Repair → outpaint → upscale → crop from winner; one repair pass for 22–27 scores | Cost + consistency |
| **Crop matrix** | Flagship deliverables: **master + 1:1 + 9:16 + OG** (cast also 4:5); derived, not re-gen | Channel unfitness |
| **Doctrine lint** | Pre-ship checklist: glyphs/text/hearts/FX budget/rail tag/stylePackId | E2 / Laeylinn class fails |
| **Rail + stylePackId tags** | Required media-job fields; missing = invalid | R13 mix |

### Compile order (hard)

```
1. Identity (name — role — prop)
2. Form / silhouette
3. Materials (whitelist only)
4. Light law
5. Environment / realm beat
6. Camera / crop
7. One domain FX (budget)
8. Motion seed
9. Positive “clean” outcomes (not negative spam)
```

## 4. Generation pipeline forever

```
0. Continuity queue item (CONTINUITY_QUEUE.md) + canon DNA load
1. Design card (schema v2) + stylePackId + rail
2. Load master still / face-or-form bible if exists (required after first approve)
3. Compile prompt from house template only
   (cast-portrait-bible | godbeast-encyclopedia-hero)
   unless RAIL-E pack explicitly set
4. Generate 2–4 candidates @ Quality 2K
   OR multi-pass edit chain from master
5. Contact sheet pick → Vision score30 breakdown
6. Doctrine lint (glyphs / text / hearts / FX budget / rail)
7. If flagship: I2V with motion seed from card (identity-preserving)
8. Crop matrix: master + 1:1 + 9:16 + OG (+ 4:5 cast)
9. Deterministic Codex overlay if public text needed
10. Write media-job.json + evidence.json + registry usedIn
11. Human approve → copy to approved/ → social / site queue
12. Rejects logged (path + reason); never silent delete of learning
```

**Invalid jobs (auto-block):** missing `rail`, `stylePackId`, `score30`, design card, or (post-approve) `masterRef`.

**Default ship bar:** score30 ≥ 28 + doctrine lint pass + human approve.

### 5.2 Hook types (Arcanea-fit only)

1. **Scale reveal** — human vs Godbeast  
2. **Prop mystery** — vial, gauntlet, harness, repaired tool  
3. **Identity stare** — eye contact cast  
4. **Material macro → pull out** — nacre / jade / resonite  
5. **Codex card flip** — deterministic name/gate appear  

**Do not use as house hooks:** power-up sparkles, isekai portal spam, multi-character fight collage, watermarked “AI art” flex.

### 5.3 Video grammar (default 6s)

| Do | Don’t |
|----|-------|
| Slow push-in or gentle orbit | Whip pans, morph faces |
| Material / light pulse | New limbs / style drift mid-clip |
| Hair / water / dust micro-motion | Busy multi-subject motion |
| Silent-first; overlay titles | Baked gen text titles |
| From approved still only | I2V from unapproved explore |

### 5.4 Packaging that kills “weird” (E rail)

1. Frame as **Codex museum card** (name · gate · one sentence).  
2. **One subject** per post.  
3. Cold audience: tighter face (cast) or pure scale (beast); **lower FX** in crop if needed.  
4. Separate product vs world lanes if distribution confuses ICP.  
5. Only `approved/` + human gate.  
6. Prefer **edit/outpaint variants** over new random gens for weekly volume.

### 5.5 Cadence (sustainable)

| Cadence | Deliverable |
|---------|-------------|
| Weekly minimum | 1 flagship still + 1 I2V loop + 3 social crops (from masters) |
| Per cast face approve | Face bible freeze → Soul candidate set |
| Per Godbeast | Form bible (3 angles + materials) before volume |
| Prestige B | 3–5 labeled pilots only after core faces lock |
