### Missing / must add (Generation Standard v1)

| Technique | Why | How |
|-----------|-----|-----|
| **Canon master still** | Face/form drift is #1 franchise killer | Approve 1 master per cast/godbeast; all gens img2img / reference from master |

| **FX budget = 1** | “Weird” = magic spam | Max one domain effect + ambient particles; no glyph/text/music notation |
| **Negative-as-positive** | Models ignore long “no X” lists | Write what *is* shown instead |
| **Contact sheet pass** | Compare seeds before ship | 2–4 candidates; pick one; log rejects |
| **Edit chain over re-roll** | Consistency | Outpaint / edit / upscale from winner rather than new seed lottery |
| **Crop matrix required** | Social fitness | Master + 1:1 + 9:16 + OG as deliverables for flagships |
| **Deterministic Codex overlay** | Public text accuracy | Name / Gate / one line via HTML-Satori, never baked gen text |
| **I2V motion grammar** | Video quality | Slow push-in, material shimmer, single ambient loop; no morph / no new limbs |
| **Doctrine lint** | Prevent E2-class fails | Pre-ship checklist: no musical notes, no letters, no cartoon hearts-as-architecture |
| **Rail tag mandatory** | Prevent chrome LARPing | `rail: world | product | experiment` on every job |
| **Style pack ID mandatory** | Prevent silent drift | `stylePackId: house-myth-tech` default |

## 4. Core design pillars (10 non-negotiables)

1. **Luxury cosmic myth-tech** — not mud fantasy, not isekai glow, not MCU spandex.  
2. **Materials whitelist only** — crystal, starlight metal, living stone, nacre, Vael crystals, etc.  
3. **Light law** — warm gold × cool cosmic blue; cosmic dusk; restrained rays.  
4. **One subject** — one cast or one Godbeast per flagship frame.  
5. **Identity lock** — face/form master + prop + silhouette.  
6. **Godbeasts are creatures** — never armored humanoids as “Godbeast origin.”  
7. **FX budget = 1** + ambient; **zero** text/glyphs/sheet music.  
8. **Encyclopedia grammar** — museum plate, not wallpaper dump.  
9. **Score ≥ 28/30** or no ship.  
10. **Human approve** before public/social.

## 6. Video & social — what to run

### Best sources for video (I2V)
| Priority | Why |
|----------|-----|
| **Godbeasts (Otome/Kaelith class)** | Scale + material shimmer + readable motion |
| **Cast close portraits** | Eye contact + prop micro-motion |
| Avoid as first I2V | Over-busy multi-subject, glyph-heavy, low silhouette |

### Motion grammar (default 6s)
- Slow push-in or orbit  
- Material / light pulse only  
- Hair / water / dust micro-motion  
- **No** face morph, limb invent, style drift  

### Social formats (from masters only)

| Format | Source | Caption job |
|--------|--------|-------------|
| 9:16 Reel | Godbeast or cast tight | Silent first 1s = silhouette; title line at 1s |
| 1:1 feed | Codex plate + overlay | Who / Gate / one fact |
| 4:5 cast | Portrait master | Vow or wound beat |
| Carousel | 3–5 plates | Role · Prop · Place · Quote |
| Product | Lab chrome + 1 framed still | “Build with memory” not “look at dragon” |

### Hook types that fit Arcanea (not generic influencer)
1. **Scale reveal** — human vs Godbeast  
2. **Prop mystery** — sealed vial, gauntlet lens  
3. **Identity stare** — eye contact cast  
4. **Material close-up** — nacre / jade / resonite macro then pull out  
5. **Codex card flip** — frame + name appears (deterministic)
