## 5. Canon visual pillars (lock these)

### Pillars (house style)
1. **Material truth** — crystal, nacre, living stone, starlight metal, liquid light; never plastic / mud-medieval default / isekai neon  
2. **Light law** — cosmic dusk; warm gold × cool cosmic blue; domain accent secondary  
3. **Silhouette law** — 50px-readable shape per cast + Godbeast (emblem test)  
4. **Prop DNA** — one signature object per cast center (Mera vial, Emilia gauntlet, Arion repaired tool, Akamoto stop-hand / harness)  
5. **Godbeasts as CREATURES** — monumental sacred beasts, not people-in-suits or origin classes  
6. **Controlled magic** — one domain effect per frame; environmental physics > particle spam  
7. **Franchise equation** (from VISUAL_DOCTRINE):  
   `CLEAN EMBLEM + HEROIC PRESENCE + ONE BEAST ANCHOR + ONE TECH ANCHOR + ONE CELESTIAL ANCHOR + GOLD-LIGHT DNA`  
8. **Emotional beat** — every flagship still answers: *what does this character want / fear / refuse in this frame?*

## 6. Pitfalls of a full anime pivot

1. **Doctrine betrayal** — VISUAL_DOCTRINE already bans “anime-bright oversaturation / generic isekai.”  
2. **Chrome collision** — Product promise is AI-lab premium; anime world as shell = LARPy SaaS.  
3. **IP indistinguishability** — Competing with infinite Niji/NovelAI same-face flood.  
4. **Soul-ID mismatch** — Photoreal Soul training pipeline optimized for current house; anime pivot resets identity investment.  
5. **Godbeast demotion** — Sacred monumental creatures become “cute companion” tropes; bonding mechanic loses gravity.  
6. **Franchise amnesia** — Style churn = audience can’t form mental model of Arcanea.  
7. **Short-term virality trap** — Spikes without shelf → no encyclopedia, no book plates, no merch silhouettes.

If warmth is the real need: ship **Rail B′ prestige illustrated**, not full anime house.

**Packaging reduces “weird” more than style pivots.** Frame as museum Codex card; one subject; cold-audience crop on face or pure scale.
