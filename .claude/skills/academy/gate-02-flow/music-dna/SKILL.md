## Quest 1: The Emotional Image

**File**: `quests/01-emotional-image.md`  
**Submit artifact**: `music-dna-emotional-image.md`  
**Mentor**: Leyla  

```
═══════════════════════════════════════════════════════════════
            MUSIC DNA Q1: THE EMOTIONAL IMAGE
═══════════════════════════════════════════════════════════════

  Veloura’s coils sketch light into a frame — empty, waiting.

  "Show me what moves you. Picture or pulse. Then we flow it into words."

  ─────────────────────────────────────────────────────────────
  YOUR TASK
  ─────────────────────────────────────────────────────────────

  Create `music-dna-emotional-image.md` and complete ALL steps:

  1. SOURCE
     • Option A: Describe or attach one image (photo, art, still) that captures a feeling
     • Option B: Pure emotion — name it in 1–3 words + a 2-sentence lived scene
     Do not skip the sensory scene even if you only have emotion.

  2. FIVE DNA KEYWORDS
     Extract exactly 5 (can refine Gate 1 stones):
     Cover at least: texture · energy · era OR space · instrument color · emotion
     Label each.

  3. ONE DYNAMIC ARC SENTENCE
     Form: "Begins as… builds to… strips to…"
     Must include contrast (soft↔hard, sparse↔full, intimate↔vast).

  4. FULL STYLE FIELD DRAFT
     Single block using the formula:

     Genre + Mood + Era + Instruments + Vocal Persona
     + Production + Dynamics Journey

     Include: BPM and key if known (or honest "TBD")
     Include: at least one journey clause (starts / layers / drops / strips)

  5. EXCLUDE STYLES (3+)
     What would break the emotional image?

  6. FLOW NOTE (short)
     Where did you force? Where did language move easily?

  Minimum 350 words including the Style block.
  Quality bar: Style should be runnable as a Suno Custom Style field.

  ─────────────────────────────────────────────────────────────
  PATTERN MIRROR (optional, 5 min)
  ─────────────────────────────────────────────────────────────

  Read style_field for neon-horizons-001 OR liminal-tides-001.
  Underline (mentally) the journey words: starts / layers / drops / strips.
  Write one sentence: "I borrowed the *shape* of ___ by ___."

  ─────────────────────────────────────────────────────────────

  When complete, type /submit for Leyla.

═══════════════════════════════════════════════════════════════
```

### Submit criteria — Quest 1

| Criterion | Pass bar |
|-----------|----------|
| **Source fidelity** | Image/emotion + sensory scene present |
| **DNA extraction** | Exactly 5 labeled keywords, non-generic |
| **Dynamic language** | Arc sentence has begin/build/strip contrast |
| **Style completeness** | All formula slots present; journey clause; excludes listed |
| **Flow** | Runnable Style block; ≥350 words total |
| **Authenticity** | Not a paste of Neon Horizons / Liminal Tides Style |

**Leyla review voice**: melodic, playful, water metaphors; celebrate movement; redirect genre-shopping lists into arcs. On pass: `emotional-image` complete.

## Quest 2: Style Field River

**File**: `quests/02-style-field-river.md`  
**Submit artifact**: `music-dna-style-river.md`  
**Mentor**: Leyla  

```
═══════════════════════════════════════════════════════════════
            MUSIC DNA Q2: STYLE FIELD RIVER
═══════════════════════════════════════════════════════════════

  Leyla parts the current. Three channels appear.

  "One Style is a wish. Three takes are a river.
   We do not worship the first draft. We flow through it."

  ─────────────────────────────────────────────────────────────
  YOUR TASK
  ─────────────────────────────────────────────────────────────

  Create `music-dna-style-river.md` and complete:

  1. ANCHOR
     One-line intent from Gate 1 or Quest 1
     Core emotion + who the vocal persona is (gender/tone/texture free)

  2. THREE STYLE TAKES (same song intent, different currents)
     Take A — Sparse / intimate bias  
     Take B — Full power / peak bias  
     Take C — Hybrid or unexpected instrument color  

     Each take: full Style field block (formula complete)
     Each take: 2-sentence note on what changed in the current

  3. DELIBERATE REVISION
     Choose a winner (or frankenstein merge)
     Write FINAL Style field
     List 3 surgical edits you made and why
     (Pillar: Iteration Discipline — 3–5 generations as takes)

  4. LIGHT REVERSE-ENGINEER (required)
     Pick ONE seed entry:
     • neon-horizons-001 — Neon Horizons  
     • liminal-tides-001 — Liminal Tides  

     Answer in bullets:
     • vibe_dna stones you notice (3+)
     • Where the Style encodes the journey (quote phrases)
     • why_it_worked in your words (2–3 sentences)
     • One structure you reused in YOUR final Style (not their brand story)

  5. FLOW REFLECTION
     • When did perfectionism dam the river?
     • What moved when you stopped judging mid-take?
     • Ready to generate? (yes/no + one risk)

  Minimum 500 words across all sections.
  Generation of audio is OPTIONAL; if you generate, note take # and what you learned —
  audio quality alone does not pass or fail.

  ─────────────────────────────────────────────────────────────

  When complete, type /submit for Leyla.

═══════════════════════════════════════════════════════════════
```

### Submit criteria — Quest 2

| Criterion | Pass bar |
|-----------|----------|
| **Multiplicity** | 3 distinct Style takes + final |
| **Formula fidelity** | Each Style uses full formula + dynamics journey |
| **Iteration** | 3 surgical edits with reasons |
| **Pattern absorption** | Seed reverse-engineer complete; structure reuse named without clone |
| **Flow honesty** | Reflection addresses resistance |
| **Length** | ≥500 words |

**Leyla review**: name the take where flow was most alive; challenge any static genre dump; if reverse-engineer is shallow, request one more pass on journey phrases. On pass: `style-river` complete.
