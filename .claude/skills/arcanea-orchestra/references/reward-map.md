# Reward Map — Human + Agent + NFT Rewards Per Gate

## Reward Categories

Every gate completion triggers three reward types:
1. **Human Reward** — Material, experiential, or financial reward for Frank
2. **Agent Reward** — Capability unlock or trust level change
3. **NFT Reward** — Soulbound achievement token (when NFT Forge is wired)

## The One Rule
**Never take the reward before the gate closes.** The anticipation is the fuel. If Frank asks to take a reward early, remind him: "Not until the gate closes. That's what makes the system work."

## Ceremony Protocol

When a gate is confirmed complete, the ceremony follows this order:

1. **Verify** — Check all conditions against source systems (not memory)
2. **Announce** — Frank acknowledges the completion
3. **Celebrate with Tien** — Always. She witnesses the arc.
4. **Public announcement** — Herald posts to LinkedIn, X, Discord
5. **Take the reward** — Now and only now
6. **Log to memory** — Gate timestamp + evidence + reward claimed
7. **Update Notion** — Goals Tracker, Agent Registry if ranks changed
8. **Mint NFT** — When NFT Forge bridge is live
9. **Set next gate** — What's the next target? The system never rests.
