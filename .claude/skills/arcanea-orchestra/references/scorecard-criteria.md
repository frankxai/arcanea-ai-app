# Weekly Scorecard Criteria

## Target: 70+ out of 90

Score each domain 1-10 based on the criteria below. Be honest — inflated scores defeat the purpose.

## Scoring Rubric

### 1. Training Sessions (Target: 4+ per week)
| Score | Criteria |
|-------|----------|
| 10 | 5+ sessions, hit PRs or personal bests |
| 8 | 4 sessions, solid performance |
| 6 | 3 sessions, decent effort |
| 4 | 2 sessions |
| 2 | 1 session |
| 0 | No training this week |

### 2. Priming Rituals (Target: 7/7 days)
| Score | Criteria |
|-------|----------|
| 10 | 7/7 days, full ritual (Tony Robbins, Wim Hof, movement) |
| 8 | 6/7 days |
| 6 | 5/7 days |
| 4 | 3-4/7 days |
| 2 | 1-2/7 days |
| 0 | No priming this week |

### 3. Content Published (Target: 5+ pieces)
| Score | Criteria |
|-------|----------|
| 10 | 7+ pieces across multiple platforms, high engagement |
| 8 | 5-6 pieces, consistent quality |
| 6 | 3-4 pieces |
| 4 | 1-2 pieces |
| 2 | Drafted but not published |
| 0 | No content |

### 4. Goal #4 Progress (Target: Daily progress)
| Score | Criteria |
|-------|----------|
| 10 | Major milestone hit (gate passed, blocker closed, feature shipped) |
| 8 | Meaningful daily progress all week |
| 6 | Progress on most days |
| 4 | Sporadic progress |
| 2 | 1-2 days of effort |
| 0 | No ecosystem progress |

### 5. Revenue Actions (Target: 3+ per week)
| Score | Criteria |
|-------|----------|
| 10 | Revenue generated + new pipeline opened |
| 8 | 3+ revenue-generating actions (outreach, listings, launches) |
| 6 | 2 revenue actions |
| 4 | 1 revenue action |
| 2 | Planned but not executed |
| 0 | No revenue actions |

### 6. Tien Quality Time (Target: Daily)
| Score | Criteria |
|-------|----------|
| 10 | Quality time every day, shared experiences |
| 8 | 6/7 days |
| 6 | 4-5/7 days |
| 4 | 2-3/7 days |
| 2 | 1/7 days |
| 0 | No quality time |

### 7. Songs Created (Target: 2+ per week)
| Score | Criteria |
|-------|----------|
| 10 | 3+ songs created and published |
| 8 | 2 songs created and published |
| 6 | 1 song published + 1 in progress |
| 4 | 1 song created |
| 2 | Worked on music but nothing finished |
| 0 | No music work |

### 8. Energy Average (Target: 8+)
| Score | Criteria |
|-------|----------|
| 10 | Consistently high energy all week, flow states achieved |
| 8 | Most days high energy, good sleep |
| 6 | Average energy, some low days |
| 4 | More low days than high |
| 2 | Low energy most of the week |
| 0 | Burnout territory |

### 9. Creation Season (Target: 5+/7 nights)
| Score | Criteria |
|-------|----------|
| 10 | 7/7 nights protected, deep work achieved |
| 8 | 5-6/7 nights |
| 6 | 4/7 nights |
| 4 | 2-3/7 nights |
| 2 | 1/7 nights |
| 0 | No creation sessions |

## Scorecard Format

```
✦ ARCANEA ORCHESTRA — Weekly Scorecard — Week of [Date]

| Domain              | Target | Actual | Score |
|---------------------|--------|--------|-------|
| Training sessions   | 4+     | [N]    | [/10] |
| Priming rituals     | 7/7    | [N/7]  | [/10] |
| Content published   | 5+     | [N]    | [/10] |
| Goal #4 progress    | Daily  | [desc] | [/10] |
| Revenue actions     | 3+     | [N]    | [/10] |
| Tien quality time   | Daily  | [N/7]  | [/10] |
| Songs created       | 2+     | [N]    | [/10] |
| Energy average      | 8+     | [N]    | [/10] |
| Creation Season     | 5+/7   | [N/7]  | [/10] |
|                     |        | TOTAL  | [/90] |

Target: 70+/90
Last week: [N]/90 ([+/-N] delta)

GATE PROGRESS: [Current Gate] → [X]% complete
LUMINA STREAK: [N] days

TOP WIN: [biggest achievement this week]
FOCUS NEXT WEEK: [lowest-scoring domain(s)]
```

## Week-over-Week Tracking

Store each scorecard in memory vault with timestamp. The `/ao scorecard` command should always show:
- This week's scores
- Last week's scores for comparison
- Trend direction per domain (↑ improving, → stable, ↓ declining)
- Rolling 4-week average for each domain
